## 字体与交互

| Token建议 | 数值 | 用途 |
|---|---|---|
| --type-page | 34px / 1.15 / 400 | 页标题，Cormorant Garamond |
| --type-section | 24px / 1.3 / 500 | 区块标题 |
| --type-subsection | 18px / 1.4 / 500 | 次级标题 |
| --type-body | 16px / 1.6 / 400 | 说明正文 |
| --type-control | 15px / 1.4 / 500 | 菜单、按钮、筛选、Tab |
| --type-event | 15px / 1.5 / 400 | 事件名称 |
| --type-meta | 14px / 1.5 / 400 | 时间、track、设备、统计说明 |

关键操作高度至少40px，常用操作44px。常规正文对比度至少4.5:1；不要将品牌金色直接用于浅底正文。主文字#232521、次文字#62665D、暖白#F7F3EB、深色#171916、香槟金#B9A27D；保留sage/clay业务语义。不要使用CSS zoom、transform scale或浏览器缩放满足指标。

沿用本地字体。中文使用支持字形的系统sans-serif回退并保持字号。当前未实现阿语；未来必须本地部署具备真实阿语字形的字体并独立验收RTL，不能默认标记通过。

## 空间分配

1440×900：顶栏约72px；导航76px；左右内容内边距32px；可用宽约1300px。页头约64–80px，减少大标题占比。KPI四等列，单条约104–120px高，位于双栏之前。

双栏gap24px；预览列约700px、事件列约576px。视频16:9，高约394px；工具栏与播放控制另计。1920下限制默认预览宽度至720px，避免再次膨胀为主背景；允许工作区居中并限制总宽。1280可按比例缩到约610px，事件仍保留约500px；低于1100px可上下排列，不压小文字。小屏KPI两列、设备列表纵排。

事件每行至少72px（最低不得小于56px）；设备/时间/track清晰分组。事件区可独立滚动，但必须给出至少约300px的阅读区域；辅助洞察移到独立Tab或帮助区，不挤压日志。Camera Network放在双栏下方全宽。自然纵向滚动可接受。

预览常用控制：Play/Pause、时间轴、倍速、Step、Reset、Expand。高级Detection/Trails放独立一行或展开工作台。预览右上与控制条均有文字Expand入口。

展开采用完整页面工作台（不做伪modal）：同一播放器与父级状态，图像扩大，事件面板可折叠，相机选择随手可达，顶栏Collapse和Esc退出。记录触发按钮与滚动位置，退出后恢复。若实现改用modal，须重新提交设计审核并实现焦点圈定/滚动锁定。
